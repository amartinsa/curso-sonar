6–20 min

El análisis en vivo

  1. Generar el token

    My Account → Security → Generate Tokens. ¡Atención! Se muestra una sola vez.

  2. Lanzar el análisis

    Debe salir BUILD SUCCESS y ANALYSIS SUCCESSFUL.

    PS> mvn clean verify sonar:sonar 
        "-Dsonar.projectKey=clave-proyecto" 
        "-Dsonar.projectName='nombre-proyecto'" 
        "-Dsonar.host.url=Url-tu-servidor-Sonarqube" 
        "-Dsonar.token=squ_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"

  3. Ver el Quality Gate

    Sin explicar nada todavía: la cabecera ya dice qué condiciones fallan.

  4. Evaluar los issues

    Solucionar los issues por nivel de criticidad: Critical › Bug › … › Code smell.

Ejemplos

CódigoReglaTipo
equals() reescrito y hashCode() ausente en Cliente java:S1206 Bug
MessageDigest.getInstance("MD5") en ServicioHuellas java:S4790 Hotspot
tipo == "VIP", métodos largos, números mágicos, código duplicado... java:S4973 Code smells

El gate rojo en el primer análisis no es un fallo.

Es el resultado esperado: está diciendo que algo no llega al listón.
