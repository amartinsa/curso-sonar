Evaluación

Todos los issues son posibles problemas de código de distinto nivel de criticidad que se pueden corregir.

Bug Reliability

Código probablemente erróneo.

Posible NullPointerException · Código crítico inalcanzable

Vulnerability Security

Código que puede provocar errores de datos.

Runtime.exec("ping " + host) con entrada del usuario · SQL inyectado mal escrito

Security Hotspot Revisión humana

Código que debe revisar un humano: posible error de lógica o no cumple el estándar.

MessageDigest.getInstance("MD5")

Code smell Maintainability

Código difícil de leer o mantener.

tipo == "VIP" por equals() · código inalcanzable

Severidad: Blocker › Critical › Major › Minor › Info. Es el impacto de la regla, no de tu proyecto. Deuda técnica: tiempo estimado en arreglarlo.

Un hotspot no tiene por qué ser un error de código: puede serlo de concepto o de lógica de negocio.

Los code smells no afectan al Quality Gate, aunque sean la mayoría.
